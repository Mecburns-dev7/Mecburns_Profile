# Virtual Assistant Portfolio Website

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Personalize before publishing
Open `index.html` in VS Code or a text editor and replace:
- `Your Name` with your preferred professional name
- `YN` with your initials
- `your.email@example.com` with your professional email address
- `Add your LinkedIn profile URL` with your actual LinkedIn URL
- The About section with accurate details about your education and experience
- Sample project descriptions after you have actually created the sample files

## Important
The portfolio uses sample project concepts. Do not claim a sample project is completed until you have created it. Keep private and confidential information off your public portfolio.

## Publish for free
You can deploy this static website using GitHub Pages or Netlify. Create an account, upload/push the website files, and follow the platform's current deployment instructions.
